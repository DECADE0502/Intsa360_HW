# Insta360 硬件提效平台使用说明

## 1. 这是什么

Insta360 硬件提效平台是一套给硬件工程师使用的本地工具平台，主要用于 BOM 处理、BOM 检查、BOM 差异比较、网表差异比较、贴片封装检查、贴片布局对照、单网络检查，以及 OrCAD Capture 脚本管理。

它不是单个 Excel 小工具，而是把硬件研发里反复做、容易漏、容易出错的检查流程做成一套固定工具。目标是让工程师在出 BOM、改版评审、贴片前检查、Capture 脚本使用时少做重复劳动，少靠人工肉眼查表。

平台主要解决这些问题：

- Capture 导出的 BOM 字段多、格式乱，手工整理容易漏。
- NC、未贴、测试点、机构件、屏蔽支架等对象容易混进最终 BOM。
- 同一个物料编码可能出现不同描述、型号、名称或等级，人工合并容易误选。
- 改版时 BOM 和网表都要对比，人工逐行看很慢。
- eMMC、DDR、BGA、连接器等高风险物料需要额外提醒。
- OrCAD Capture 的 Tcl 小脚本越来越多，手动安装和同步很麻烦。

一句话：平台把硬件工程师常做的 BOM 和网表检查固化成可重复、可追溯、可导出报告的流程。

## 2. 什么时候用

### 2.1 从 Capture 导 BOM 给 PLM/OA

用 **BOM 处理**。

适合场景：

- 原理图阶段导出 BOM。
- 需要生成 PLM/OA 可导入格式。
- 需要过滤 NC/未贴。
- 需要确认 SH 位号是否为屏蔽支架。
- 需要处理相同物料编码但描述不一致的问题。
- 需要最终 BOM 预览和打包交付。

### 2.2 导入 PLM/OA 前自查

用 **BOM 风险检查**。

适合场景：

- BOM 已经整理好，准备提交前。
- 需要检查 PCB 裸板、屏蔽支架、NC、重复位号、数量一致性。
- 需要提醒 eMMC/DDR 等硬件版本敏感物料。
- 希望提前发现导入或评审风险。

### 2.3 改版后确认 BOM 变化

用 **BOM 差异比较**。

适合场景：

- V01 到 V02 改版。
- 二供替换。
- 试产后 BOM 调整。
- 想确认哪些位号新增、删除、换料、参数变化。
- 想从料号用量角度看采购/PLM 变化。

### 2.4 改版后确认网表变化

用 **网表差异比较**。

适合场景：

- 原理图或 PCB 修改后，需要确认网络节点变化。
- 需要检查关键网络是否新增、删除、少接、多接。
- 需要确认封装变化。
- 需要对比两个 Allegro 导出的 `allegro` 目录。

### 2.5 贴片前确认封装和 BOM 是否一致

用 **贴片封装检查**。

适合场景：

- 已经有 Allegro 网表目录。
- 已经有处理后的 PLM/OA 成品 BOM。
- 需要确认网表 footprint 和 BOM 描述、型号、封装是否一致。
- 需要检查同一物料编码是否对应多个封装。
- 需要确认 BOM 缺位号或 BOM 多余位号。

### 2.6 出图前查 NC 和单网络

用 **单网络检查**。

适合场景：

- 出图前检查 NC 网络。
- 检查只有单一位号的网络。
- 排查悬空、漏连、网络命名异常。

### 2.7 管理 Capture 小脚本

用 **插件管理**。

适合场景：

- 想把某个 Tcl 功能挂到 Capture 菜单。
- 想取消某个脚本的菜单入口。
- 想同步团队新增脚本。
- 不想每个人手工复制 Tcl 文件。

## 3. 安装与第一次启动

### 3.1 安装前准备

安装前建议确认：

- 电脑已安装 OrCAD Capture。
- 如果要使用网表差异、贴片封装、单网络检查，需要能从 Allegro 导出 `pstxnet.dat`、`pstxprt.dat`。
- 如果公司电脑拦截未知程序，第一次运行安装包时可能需要选择“仍要运行”或让 IT 放行。
- 安装和更新过程中不要关闭安装窗口或平台窗口。

### 3.2 使用安装包安装

拿到安装包后，双击：

```text
Insta360_HW_Setup.exe
```

按安装向导操作即可。一般情况下使用默认安装路径，不需要手动改目录。

常见安装目录是：

```text
C:\Program Files\Insta360\HWAgent
```

安装过程中会自动完成：

- 安装平台主程序。
- 放置平台运行所需文件。
- 创建主入口 `Insta360_HW.exe`。
- 准备本地数据目录，用于保存上传文件、输出报告和历史记录。
- 部署 OrCAD Capture 菜单脚本。
- 准备更新、卸载和日志功能。

### 3.3 安装完成后会有什么

安装完成后，电脑上会有：

| 项目 | 说明 |
|---|---|
| `Insta360_HW.exe` | 平台主入口，双击打开平台 |
| 平台安装目录 | 保存平台程序、工具、脚本和本地数据 |
| 本地 Web 平台 | 浏览器中打开，默认地址 `http://127.0.0.1:8765` |
| OrCAD Capture 菜单 | Capture 重启后出现 `insta360_HW` 菜单 |
| 数据目录 | 保存上传文件、输出报告、历史记录和运行日志 |
| 更新/集成入口 | 平台左侧底部可检查更新、立即更新、查看更新公告、移除 Cadence 集成 |

注意：平台是本地运行的工具，BOM、网表和报告默认都在本机处理。

### 3.4 第一次打开平台

安装完成后，双击：

```text
Insta360_HW.exe
```

平台会启动本地服务，并自动打开浏览器页面：

```text
http://127.0.0.1:8765
```

第一次启动可能会等待几秒。如果看到等待页面或启动动画，等它自动跳转即可。

如果服务已经打开，再次双击 `Insta360_HW.exe` 会复用已有服务，不需要重复启动多个窗口。

### 3.5 第一次打开后建议做什么

第一次打开平台后，建议按这个顺序检查：

1. 看左侧是否能看到 BOM 处理、BOM 差异比较、BOM 风险检查、网表差异比较、贴片封装检查、单网络检查、插件管理。
2. 打开 **系统状态**，确认没有明显失败项。
3. 打开 **插件管理**，看平台是否识别到 Capture 脚本。
4. 打开 OrCAD Capture，重启一次 Capture。
5. 在 Capture 菜单中确认是否出现 `insta360_HW`。
6. 用一份测试 BOM 试跑一次 BOM 处理或 BOM 风险检查。

### 3.6 Capture 里安装完成后会多什么

重启 OrCAD Capture 后，菜单中应出现：

```text
insta360_HW
```

菜单里固定有两个入口：

- `Open Platform`：打开平台首页。
- `Export and Process BOM`：导出当前设计 BOM，并自动进入 BOM 处理。

其他脚本是否出现在 Capture 菜单中，由平台的 **插件管理** 控制。比如 NC 切换、GND 网络名显示/隐藏、网络名替换、脱敏等脚本，只有在插件管理里启用后才会挂到 Capture 菜单。

### 3.7 如果 Capture 菜单没有出现

如果安装后 Capture 里没有 `insta360_HW` 菜单，按下面顺序处理：

1. 先完全关闭并重新打开 OrCAD Capture。
2. 打开平台，进入 **系统状态**，看 Cadence 集成是否正常。
3. 打开 **插件管理**，复制底部的 Capture 热更新指令。
4. 在 Capture Command Window 执行：

```tcl
source [file join $env(HOME) "cdssetup/OrCAD_Capture/tclscripts/capAutoLoad/iac_bom_tool.tcl"]
```

5. 如果仍然没有菜单，重新运行安装包或联系维护人员检查 Capture 的 Tcl 自动加载目录。

### 3.8 日常怎么打开

日常使用有两种入口：

- 直接双击 `Insta360_HW.exe`，进入平台首页。
- 在 Capture 里点击 `insta360_HW -> Export and Process BOM`，直接导出并进入 BOM 处理。

如果只是做 BOM 对比、风险检查、网表对比、封装检查，直接从平台左侧进入对应工具即可。

## 4. 推荐主流程

### 4.1 正常出 BOM 流程

```text
Capture 点击 Export and Process BOM
  -> 自动打开 BOM 处理
  -> 确认成品名称、父项编码、父项描述
  -> 确认 SH 屏蔽支架
  -> 确认相同编码冲突如何合并
  -> 生成 PLM/OA BOM
  -> 查看最终 BOM 预览
  -> 进入 BOM 风险检查
  -> 下载交付 zip
```

### 4.2 改版评审流程

```text
旧 BOM + 新 BOM
  -> BOM 差异比较
  -> 看新增、删除、换料、参数差异、料号用量变化

旧 allegro 目录 + 新 allegro 目录
  -> 网表差异比较
  -> 看网络节点、Pin、封装变化

新 allegro 目录 + 新 PLM/OA BOM
  -> 贴片封装检查
  -> 看缺位号、多余位号、多封装、高风险封装
```

### 4.3 出图前检查流程

```text
Allegro 网表目录
  -> 单网络检查
  -> 查 NC 网络和单一位号网络

最终 BOM
  -> BOM 风险检查
  -> 查 PCB、屏蔽支架、NC、重复位号、数量和优选等级
```

## 5. BOM 处理

### 5.1 作用

把 Capture 原始 BOM 处理成可导入 PLM/OA 的成品 BOM，同时输出 NC/未贴汇总和最终 BOM 预览。

### 5.2 输入

- Capture 导出的原始 BOM Excel。
- 成品名称。
- 父项编码。
- 父项描述。
- 输出格式：PLM、OA，或两者都输出。
- 可选附加物料：PCB 裸板、屏蔽支架、其他结构/辅料。

如果从 Capture 菜单 `Export and Process BOM` 进入，原始 BOM 会自动带入，不需要手动上传。

### 5.3 操作步骤

1. 打开 **BOM 处理**。
2. 如果是手动进入，上传 Capture 原始 BOM。
3. 填写成品名称、父项编码、父项描述。
4. 选择输出 PLM、OA 或两者。
5. 如有附加物料，补充编码、名称、型号、描述、数量和位号。
6. 点击开始处理。
7. 如果提示 SH 位号，确认这些物料是否为屏蔽支架。
8. 如果提示疑似工艺件，勾选确实需要贴装的物料；未勾选项默认进入 NC 汇总。
9. 如果提示编码冲突，选择推荐合并方式，或逐个选择保留哪个字段。
10. 查看最终 BOM 预览。
11. 继续做风险检查。
12. 下载输出文件或 zip 包。

### 5.4 SH 屏蔽支架提醒

平台会识别 SH 开头位号，并提示疑似屏蔽支架。

注意：

- SH 是屏蔽支架，不是屏蔽罩。
- BOM 处理只管屏蔽支架。
- 确认为屏蔽支架后，应进入最终 BOM。
- 不应把 SH 支架直接当 NC 过滤掉。

### 5.5 疑似工艺件确认

贴装判定以物料属性为主，不再仅凭 `TP`、`JP`、`H` 等位号前缀直接过滤有料号物料。没有料号或 Value 明确为 `NC/DNP` 的行仍进入 NC 汇总；有料号且描述、名称、型号或封装命中测试点、跳线、安装孔、定位孔、Fiducial、Screw 等独立关键字时，平台会要求确认。

- 默认不勾选：作为疑似工艺件进入 NC 汇总。
- 勾选“装机”：进入最终 PLM/OA BOM。
- `SH` 位号仍优先走屏蔽支架确认，不会被普通工艺件规则覆盖。
- 普通有料号物料即使位号是 `TP/JP/H/MH/MTG`，只要物料描述未命中工艺关键字，也会进入最终 BOM。

### 5.6 编码冲突合并

如果同一个物料编码出现不同描述、型号、名称、等级，平台会暂停并提示用户确认。

可选方式：

- 推荐合并：平台按推荐规则自动选择字段。
- 手动合并：逐个冲突项选择保留哪个描述、型号、名称、等级。

建议：

- 优先保留和 PLM/OA 口径一致的字段。
- 如果同一编码确实是同一颗料，只是描述格式不同，可以合并。
- 如果同一编码对应不同规格，要先回到物料库或原始 BOM 查清楚，不要直接放行。

### 5.7 输出

常见输出包括：

- PLM BOM。
- OA BOM。
- NC/未贴器件汇总。
- 最终 BOM 预览。
- 打包 zip。

## 6. BOM 风险检查

### 6.1 作用

对单份 BOM 做导入前体检，提前发现常见漏项和风险。

### 6.2 操作步骤

1. 打开 **BOM 风险检查**。
2. 上传待检查 BOM，推荐使用 BOM 处理后生成的 PLM/OA BOM。
3. 点击运行。
4. 按页面中的检查项逐项确认。
5. 下载风险检查报告。

### 6.3 会检查什么

| 检查项 | 说明 |
|---|---|
| PCB 裸板 | PCBA BOM 通常应包含 PCB 裸板 |
| 屏蔽支架 | 如设计需要 SH 支架，应确认已进入 BOM |
| NC/未贴器件 | 防止未贴器件混入最终 BOM |
| 机构件/螺丝/孔 | 防止非贴片对象误入贴片 BOM |
| 测试点/跳线/工艺对象 | 提醒这类对象通常不进入最终贴片 BOM |
| 重复位号 | 同一位号不应被多个物料重复占用 |
| 空编号行 | 有位号但物料编码为空需要处理 |
| 数量=位号数 | 检查数量和位号数是否一致 |
| 位号/器件类型 | 如 R 位号却识别为电容/电感，会提示 |
| 物料优选等级 | 非“优选/正常”的等级会提醒 |
| 硬件版本敏感物料 | eMMC/DDR 需要核对硬件版本号、容量、速率和替代关系 |

### 6.4 怎么看结果

- `通过`：通常可以放行。
- `提示`：不一定是错误，但需要知道它存在。
- `警告`：建议处理或人工确认后再提交。

重点关注：

- 重复位号。
- 数量和位号数不一致。
- NC/未贴混入最终 BOM。
- SH 屏蔽支架缺失。
- eMMC/DDR 版本相关提醒。

## 7. BOM 差异比较

### 7.1 作用

比较两份 BOM，帮助确认改版到底改了什么。

它不是简单比较 Excel 单元格，而是按硬件工程师关心的方式看：

- 位号有没有新增。
- 位号有没有删除。
- 位号有没有换料。
- 料号用量有没有变化。
- 描述、型号、编码是否不一致。
- 两份 BOM 各自有没有风险。

### 7.2 操作步骤

1. 打开 **BOM 差异比较**。
2. 上传旧版/基准 BOM。
3. 上传新版/待确认 BOM。
4. 点击开始对比。
5. 先看顶部统计。
6. 再按新增、删除、换料、参数差异筛选。
7. 选中位号后，看左右字段对照。
8. 查看料号用量变化。
9. 下载差异报告。

### 7.3 结果怎么判断

| 类型 | 怎么理解 |
|---|---|
| 一致 | 两份 BOM 在该位号上无关键差异 |
| 换料 | 同一位号物料编码变化，优先确认 |
| 新增贴装 | 新版有，旧版没有 |
| 删除/未贴 | 旧版有，新版没有 |
| 参数差异 | 编码可能没变，但型号/描述等字段变化 |

### 7.4 推荐看法

改版评审时优先看：

1. 换料。
2. 新增贴装。
3. 删除/未贴。
4. 参数差异。
5. 料号用量变化。
6. BOM 风险检查页。

## 8. 网表差异比较

### 8.1 作用

比较两个 Allegro 网表目录，确认网络、节点、Pin 和封装变化。

### 8.2 输入

选择两个 Allegro 目录，例如：

```text
D:\desktop\IAC4功耗版\IAC4_MB_V05\allegro
```

目录中应包含：

```text
pstxnet.dat
pstxprt.dat
```

直接选择目录即可，平台会自动识别文件。

### 8.3 操作步骤

1. 打开 **网表差异比较**。
2. 选择旧版 Allegro 目录。
3. 选择新版 Allegro 目录。
4. 点击开始比较。
5. 查看新增网络、删除网络、节点变化、Pin 变化、封装变化。
6. 对关键网络优先人工确认。
7. 下载差异报告。

### 8.4 重点关注

重点看这些网络或对象：

- DDR。
- eMMC。
- MIPI。
- USB。
- 晶振/时钟。
- 复位。
- 电源使能。
- 关键电源网络。
- 高速连接器。

如果 BOM 显示某个器件换料，但网表没有对应变化，要确认是否只是 BOM 替代；如果网表变化但 BOM 没变化，要确认是否漏更新 BOM。

## 9. 贴片封装检查

### 9.1 作用

检查 Allegro 网表封装和最终 PLM/OA BOM 的描述、型号、封装字段是否一致。

主要防止：

- BOM 封装描述和 PCB footprint 不一致。
- 同一物料编码对应多个不同 footprint。
- 网表有位号但 BOM 中缺失。
- BOM 有位号但网表中不存在。
- 高风险封装没有被注意到。

### 9.2 输入

- Allegro 网表目录，必须包含 `pstxprt.dat`。
- 已处理后的 PLM/OA 成品 BOM。

注意：这里不要上传 Capture 原始 BOM。贴片封装检查应该使用 BOM 处理后生成的 PLM/OA BOM。

### 9.3 操作步骤

1. 打开 **贴片封装检查**。
2. 选择 Allegro 网表目录。
3. 选择已处理后的 PLM/OA BOM。
4. 点击开始检查。
5. 左侧按分类筛选：重点、需确认、缺位号、多余、多封装、高风险、已跳过、全部。
6. 中间查看当前位号详情。
7. 右侧查看复核规则。
8. 下载封装检查报告。

### 9.4 结果分类

| 分类 | 含义 |
|---|---|
| 通过 | 网表封装和 BOM 字段匹配 |
| 近似通过 | 识别到常见尺寸或供应商型号近似匹配 |
| 需要确认 | 没有可靠匹配，需要人工看 |
| BOM 缺位号 | 网表有该位号，BOM 没有 |
| BOM 多余位号 | BOM 有该位号，网表没有 |
| 同料多封装 | 同一个物料编码对应多个网表封装 |
| 高风险封装 | BGA、QFN、eMMC、DDR、连接器等需要重点关注 |
| 已跳过 | NC、测试点、短接、安装孔或非贴片工艺对象 |

### 9.5 怎么处理重点项

- `BOM 缺位号`：确认是否漏导、误删、未贴或不应进 BOM。
- `BOM 多余位号`：确认是否手工添加、机构辅料、位号错误。
- `同料多封装`：确认同一个编码是否真的能对应多个封装；通常需要拆料号或修正封装。
- `高风险封装`：即使通过，也建议人工看一眼，尤其是 BGA、DDR、eMMC、连接器。
- `需要确认`：看网表封装、BOM 型号、描述、物料名称是否能对应。

## 10. 贴片布局对照

### 10.1 作用

把贴片坐标、处理后的 BOM 和可选的 Cadence 网表放在同一块板图上核对，主要用于贴片资料发出前和首件检查前确认：

- 元件是否有坐标、是否落在板框内、正反面是否正确。
- NC/未贴位号是否与处理结果一致。
- BOM、贴片坐标、网表三方位号是否有漏项或多项。
- 同一位号在三份资料中的封装是否冲突。
- 首件应该按什么顺序核对，并导出可打印的 A3 横向检查表。

### 10.2 输入要求

1. **SMT 资料文件夹**：文件夹根目录必须包含 `XY.txt`，文件名大小写不限。坐标文件必须声明 `UUNITS=MM` 或 `UUNITS=MILS`。
2. **板轮廓**：推荐在同一文件夹放 DXF，并把板框放在 `OUTLINE`、`BOARD_OUTLINE`、`BORD` 或 `BOARD` 图层。没有可用 DXF 时，平台会尝试从 Gerber 范围推断矩形边界。
3. **处理后的 BOM**：选择 BOM 处理工具生成的 PLM 或 OA 成品 BOM，不要选择 Capture 原始 BOM。
4. **NC 汇总**：如果成品 BOM 同目录存在文件名含 `NC未贴` 的 Excel，平台会自动识别，不需要单独选择。
5. **Cadence 网表目录（可选）**：用于三向一致性检查，目录中应同时包含 `pstxnet.dat` 和 `pstxprt.dat`。不选择网表时，布局和首件功能仍可使用。

板轮廓确实无法从资料中识别时，可在自动化调用中通过 `outline_bbox_mm` 指定矩形范围；日常界面使用建议优先修正 DXF 图层或重新导出板框，避免人工范围与真实异形板不一致。

### 10.3 操作步骤

1. 打开 **贴片布局对照**。
2. 填写 SMT 资料文件夹路径。
3. 选择处理后的 PLM/OA BOM；需要三向检查时再填写 Cadence 网表目录。
4. 点击开始分析，等待板图和三类结果生成。
5. 在 **NC 布局** 中筛选正面、背面和 NC 器件；点击左侧位号会在板图定位，框选板图也会同步更新位号列表。
6. 在 **首件核对** 中按正反面、风险和关键词筛选，逐行填写或打印 QC 核对表。
7. 在 **三向一致性** 中先看漏布局、漏 BOM、漏网表和封装冲突，再点击问题位号回到板图定位。
8. 下载首件核对 Excel，或使用 A3 横向打印。

### 10.4 结果怎么判断

| 结果 | 建议处理 |
|---|---|
| 漏布局 | BOM 或网表有位号，但 XY 没坐标；先确认是否漏出坐标、漏放器件或属于非贴片物料 |
| 漏 BOM | XY 或网表有位号，但成品 BOM 没有；确认是否误判 NC、漏料或不应进 BOM |
| 漏网表 | XY 或 BOM 有位号，但 `pstxprt.dat` 没有；确认网表版本和导出目录 |
| 封装冲突 | 对照 XY、BOM 型号/描述/封装和 `pstxprt.dat`，不要只按相似文字放行 |
| 高风险封装 | BGA、QFN、DDR、eMMC 和连接器等应在首件时重点核对方向、版本和焊接工艺 |

### 10.5 常见错误提示

- `SMT 文件夹缺少 XY.txt`：确认选择的是贴片资料根目录，并检查文件是否被改名。
- `XY 文件缺少 UUNITS 声明`：重新按标准格式导出坐标，不能靠猜测单位继续处理。
- `未在 DXF 中定位板轮廓层`：把真实板框放到约定图层，或重新导出只含板框的 DXF。
- `SMT 文件夹未找到 DXF 或 Gerber`：补充板轮廓文件后重试。
- `缺少 pstxnet.dat` / `缺少 pstxprt.dat`：确认选择的是同一版 Allegro 网表输出目录；不需要三向检查时可不填网表目录。
- `输入不存在`：路径可能被移动、网络盘断开或历史工作区保存了旧路径，重新选择当前资料。

## 11. 单网络检查

### 11.1 作用

提取 NC 网络和只有单一位号的网络，用于出图前自查。

### 11.2 操作步骤

1. 打开 **单网络检查**。
2. 选择 Allegro 网表目录。
3. 点击运行。
4. 查看网络名、类型、位号、节点/Pin、位号数、节点数。
5. 下载检查报告。

### 11.3 怎么看

- `NC 网络`：确认是否符合设计预期。
- `单一位号网络`：确认是否悬空、漏连或命名异常。

不要只看数量，要重点看关键器件附近的单网络。

## 14. 更新和卸载

### 14.1 检查更新

点击 **检查更新** 只检查远端是否有新版本，不会修改本地文件。

### 14.2 立即更新

点击 **立即更新** 会开始更新平台。更新时会显示进度和日志。

更新通常会保留：

- 历史记录。
- 上传文件。
- 输出文件。
- 本地配置。
- 用户自定义脚本。

更新后如页面没有变化，可以刷新浏览器或重新打开平台。

### 14.3 移除 Cadence 集成

如果只想让 Capture 菜单里不再出现平台入口，点击 **移除 Cadence 集成**。

这会移除 Capture 自动加载脚本，但保留平台本体和数据。

### 14.4 卸载平台

完整卸载请通过 Windows 设置里的应用卸载，或重新运行 `Insta360_HW_Setup.exe` 后选择 `Uninstall existing version`。

平台网页内不提供完整卸载按钮，避免本地 Web 服务删除自身时出现进度卡住、目录残留或注册表状态不一致。

如果只是暂时不用 Capture 菜单，优先使用“移除 Cadence 集成”。这个操作只移除 Capture 自动加载脚本，不删除平台本体、历史记录和本地数据。

## 16. 使用注意事项

1. BOM 处理尽量使用 Capture 正确导出的原始 BOM。
2. 贴片封装检查必须使用处理后的 PLM/OA BOM，不要用 Capture 原始 BOM。
3. 网表类工具直接选择 Allegro 目录，不要手动挑单个 dat 文件。
4. SH 开头位号是屏蔽支架候选，必须人工确认。
5. 屏蔽罩不属于 BOM 处理里的贴片流程，不要和屏蔽支架混在一起。
6. eMMC、DDR 出现时，要核对硬件版本号、容量、速率和替代关系。
7. 同一编码但描述/型号/名称/等级冲突时，不要无脑合并。
8. 高风险 Tcl 脚本执行前先备份设计。
9. 更新前如果正在处理关键项目，先下载当前输出文件。
10. 完整卸载只通过 Windows 设置或 `Insta360_HW_Setup.exe` 执行，平台网页内只负责移除 Cadence 集成。

## 17. 建议团队使用口径

为了让团队使用结果一致，建议约定：

- 所有正式 BOM 都先经过 BOM 处理。
- 提交 PLM/OA 前必须跑 BOM 风险检查。
- 改版评审必须附 BOM 差异报告。
- 涉及原理图/PCB 改动时，必须附网表差异报告。
- 贴片前必须跑贴片封装检查。
- 新增 Capture 脚本必须通过插件管理挂载，不手动改菜单。
- 更新平台前后，用同一组样例 BOM/网表做一次回归。

## 18. 后续可以继续做什么

平台后续可以继续补这些硬件工程师真正会用的工具：

- **版本变更影响报告**：把 BOM 差异、网表差异、封装检查和关键物料提醒合成一份改版报告。
- **关键网络专项检查**：DDR、eMMC、MIPI、USB、时钟、复位、电源使能等网络自动检查。
- **器件库属性体检**：检查 Capture 器件是否缺编码、缺封装、缺型号、字段不规范。
- **DFM/贴片准备清单**：自动整理 NC、测试点、安装孔、屏蔽支架、特殊工艺、高风险封装。
- **评审包一键生成**：把 BOM、网表、风险报告、封装报告和日志打成一个评审 zip。
- **替代料一致性检查**：检查同一物料或替代料的封装、规格、等级、描述是否一致。

## 19. 总结

Insta360 硬件提效平台的核心价值，是让 BOM 整理、风险检查、版本对比、网表检查、封装复核和 Capture 脚本管理形成统一流程。它不能替代硬件工程师判断，但可以把大量重复、琐碎、容易漏的检查提前自动筛出来，让工程师把精力放在真正需要判断的设计问题上。
