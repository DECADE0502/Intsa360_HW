# Insta360 硬件提效平台更新说明

## 平台内更新

在左侧边栏点击「检查更新」。平台只读取官方 Release 的 `update-manifest-v3.json`，并依次完成：

1. 校验 Ed25519 发布签名。
2. 校验运行包文件名、大小和 SHA256。
3. 下载到 `%LOCALAPPDATA%\Insta360_HW\lifecycle\v3` 的事务目录。
4. 安全展开并复核产品、版本、提交、文件集合和更新公钥。
5. 请求管理员授权，把完整候选运行时写入新的版本目录。
6. 原子切换 `installation.json`，重新部署自有 Cadence 集成并验证后端。

下载与暂存阶段可以取消；进入提交阶段后不能取消。失败或进程中断时，启动器会先恢复上一份可用运行时，再启动平台。

## 0.3.3 升级到 0.4.0

`0.3.3` 使用旧目录布局，不能直接写入 V3 运行包。它会通过兼容清单看到新版公告，但更新按钮会要求使用 `Insta360_HW_Setup.exe`。完成这一次 Setup 升级后，后续版本可以继续使用平台内 OTA。

## 版本与信任规则

- 版本号必须单调递增；同版本不同提交和所有自动降级都会被拒绝。
- 运行时不能替换 `config/update_public_key.pem`，因此普通 OTA 无法悄悄更换信任锚。
- 清单签名、资产哈希、运行包身份或 ZIP 路径任一校验失败，当前安装都不会被切换。
- Setup 可执行文件与运行包来自同一份本地构建目录，并在发布前后按同一清单复验。

需要降级或跨越不兼容的最低更新器版本时，请使用目标版本的 Setup，并在维护页明确选择重新安装。
