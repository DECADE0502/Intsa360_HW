# ADR: SMT 位号视图坐标源

## 状态

已替代。2026-08-04 起，旧的 PDF 文本提取与 PDFium 页面渲染方案不再进入运行主链。

## 决策

- `XY.txt` 是器件坐标、面别、旋转和封装的唯一来源。
- 板面由全部 XY 位号的包络和显示边距生成，不读取 DXF 板框。
- SMD/REF PDF 仅作为“打开原始位号图”的人工参考文件，不做文字提取、坐标配准或页面栅格化。
- BOM 处理结果按物理位号与 XY 关联，显示贴装、NC、非贴片、仅 BOM 和仅坐标五类状态。
- 旧的 `refdes_viewer`、PDFium 运行依赖和页面图片缓存全部移除。

## 原因

真实样本中 XY 覆盖 1037 个器件位号，而 PDF 文字层只能提取约 77%。以 PDF 作为坐标来源会漏掉密集小器件，并引入配准、页面缓存和大图加载成本；XY 可直接给出完整、确定的工程坐标。
