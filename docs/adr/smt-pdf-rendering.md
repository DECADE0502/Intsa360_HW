# ADR: SMT 位号视图坐标源与底图

## 状态

生效。2026-08-04 起，贴片视图使用 XY 定位、PDF 底图和共有位号自动配准。

## 决策

- `XY.txt` 是器件坐标、面别、旋转和封装的权威来源。
- SMD/REF PDF 是真实位号图底图；PDF 文字层只用于提取共有位号配准锚点，不作为完整坐标源。
- 每个 PDF 页面分别与 XY 正反面候选做六参数仿射拟合，按有效锚点数自动配对。
- 拟合执行一次 `3 × 残差中位数` 离群剔除。锚点少于 20 或残差中位数超过 0.5 mm 时拒绝打点。
- 底图按配准后的 XY 包络裁剪并缓存 PNG；背面使用 PDF 页面原始视角，不再额外镜像。
- 贴装状态只由集合关系确定：`placed = XY ∩ BOM`、`nc = XY - BOM`、`bom_only = BOM - XY`。
- 可选 Allegro 网表复用现有封装检查逻辑，结果按位号叠加在同一视图并保留 Excel 报告。

## 原因

XY 能覆盖全部器件位置，但自绘板面缺少真实丝印和器件轮廓；PDF 有真实图面，但文字层不能覆盖全部位号。两者通过大量共有位号自动配准，可以同时获得完整坐标覆盖、真实位号图和可量化的配准质量。
