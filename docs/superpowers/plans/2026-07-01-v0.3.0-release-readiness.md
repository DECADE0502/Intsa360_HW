# Insta360 HW v0.2.16 → v0.3.0 发布就绪实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 v0.2.16 传播使用 lifecycle review 中发现的 7 大 Blocker + 15 项 High + 20+ 项 Medium,达到可以对外公开分发的发布就绪状态

**Architecture:**
- **五个大阶段(Stage)按 lifecycle 排布**:分发就绪 → 安装可靠 → 首次运行体验 → OTA 安全闭环 → 卸载与残留
- **每个 Stage 分小任务(Task),每 Task 拆到 2-5 分钟的原子 step**
- **两级验收**:每 Step 有 AI 自动跑的 verify command;每 Stage 有人工验收清单(手工冒烟)

**Tech Stack:** Python (FastAPI-like http.server) · React/TypeScript · PowerShell · Inno Setup · C# .NET Framework · Tcl · pytest

**基线**: v0.2.16 (commit `7558820`), 主要问题清单见 `.omc/plans/review_fix_tasks_v2.md`

## 验收模型

**Step 级(AI 自动验收)**
- 每个 step 结尾必有一个 `Run:` 命令 + `Expected:` 预期输出
- AI 跑完看到预期输出 → 勾 checkbox → 进入下一 step
- 未匹配 → 停下诊断,不 fake 结果

**Task 级(AI 汇总验收)**
- 每 Task 末尾有 "Task 验收" 段落,列 4-6 条 grep/pytest/npm 断言
- 全通过才能标 Task done、`git commit`

**Stage 级(人工验收)**
- 每 Stage 末尾有 "人工验收清单"
- 包含:构建产物冒烟、隔离 VM 装/卸/OTA 冒烟、UI 手工操作、日志检查
- 人手动跑并勾选,通过才 bump minor 版本、才推进下一 Stage

**全局约束**
- 每 step 只做一件事,失败不越权修其他
- `git commit` 一句话解释 why,不解释 what
- 禁改 `data/`、`plugins/user/`、`config/local.json`
- 禁用 `git reset --hard` / `--no-verify` / `--force-push main`

创建 `scripts/lib/EmbeddedPython.ps1`:
```powershell
$script:HwAgentPythonVersion = "3.11.9"
$script:HwAgentPythonZipUrl = "https://www.python.org/ftp/python/$script:HwAgentPythonVersion/python-$script:HwAgentPythonVersion-embed-amd64.zip"
$script:HwAgentPythonZipSha256 = "1a3169e19b8bc3faa5b71b8a25ea6a54c04c2ef26eaa2f0a5e75dbaa4b7dd6b1"  # 从 python.org 官方 SHA256SUM 查
$script:HwAgentOpenpyxlWheelUrl = "https://files.pythonhosted.org/packages/.../openpyxl-3.1.5-py2.py3-none-any.whl"
$script:HwAgentOpenpyxlSha256 = "..."

function Download-EmbeddedPython {
  param([Parameter(Mandatory=$true)][string]$OutDir)
  New-Item -ItemType Directory -Force -Path $OutDir | Out-Null
  $zip = Join-Path $OutDir "python-embed.zip"
  Invoke-WebRequest -Uri $script:HwAgentPythonZipUrl -OutFile $zip -UseBasicParsing
  $hash = (Get-FileHash -Algorithm SHA256 -Path $zip).Hash.ToLower()
  if ($hash -ne $script:HwAgentPythonZipSha256) { throw "Python embed zip SHA256 mismatch: $hash" }
  Expand-Archive -Path $zip -DestinationPath $OutDir -Force
  Remove-Item -Force $zip
  # 打开 python311._pth,启用 site 模块以便识别 site-packages
  $pth = Get-ChildItem "$OutDir\python*._pth" | Select-Object -First 1
  (Get-Content $pth.FullName) -replace '^#import site', 'import site' | Set-Content $pth.FullName -Encoding ASCII
}

function Install-OpenpyxlWheel {
  param([Parameter(Mandatory=$true)][string]$PythonDir)
  # 下载 wheel + 依赖 wheel (et_xmlfile),校验后解压到 site-packages
  $wheelDir = Join-Path $PythonDir "wheels"
  New-Item -ItemType Directory -Force -Path $wheelDir | Out-Null
  Invoke-WebRequest -Uri $script:HwAgentOpenpyxlWheelUrl -OutFile (Join-Path $wheelDir "openpyxl.whl") -UseBasicParsing
  # ... hash 校验,expand 到 site-packages
}
```

```powershell
function Read-HwAgentNotice { param([Parameter(Mandatory=$true)][string]$Path)
  Get-Content -Raw -LiteralPath $Path | ConvertFrom-Json }

function Write-HwAgentNotice { param([Parameter(Mandatory=$true)][object]$Notice, [Parameter(Mandatory=$true)][string]$Path)
  $Notice | ConvertTo-Json -Depth 10 | Set-Content -Encoding UTF8 -LiteralPath $Path }

function Assert-HwAgentNoticeHasAssets { param([Parameter(Mandatory=$true)][string]$Path)
  $n = Read-HwAgentNotice -Path $Path
  if (-not $n.assets -or $n.assets.Count -eq 0) {
    throw "UPDATE_NOTICE.json.assets is empty: run publish_release.ps1 before tagging"
  }
  foreach ($a in $n.assets) {
    if (-not $a.sha256 -or $a.sha256.Length -ne 64) { throw "asset $($a.name) missing sha256" }
  }
}
```

```typescript
import { ApiError } from './errors';
type ApiOpts = { signal?: AbortSignal; timeoutMs?: number };

export async function apiCall<T = any>(path: string, init: RequestInit = {}, opts: ApiOpts = {}): Promise<T> {
  const ctrl = new AbortController();
  const timer = opts.timeoutMs ? setTimeout(() => ctrl.abort(), opts.timeoutMs) : null;
  const signal = opts.signal ?? ctrl.signal;
  try {
    const res = await fetch(path, { ...init, signal });
    const payload = await res.json();
    if (!res.ok || payload.status === 'error') {
      throw new ApiError(
        payload.error_kind ?? 'HttpError',
        payload.user_message ?? payload.error ?? res.statusText,
        res.status, payload
      );
    }
    return payload as T;
  } finally { if (timer) clearTimeout(timer); }
}
```

**关键:Inno 的 `[UninstallDelete]` 是 additive(额外删),不是 exclusive。要真正保留必须**不列在 `[Files]` 且卸载后不删**。当前 `[Files]` `Excludes` 语义只影响安装期,不影响卸载。

**方案**: 用 `[UninstallDelete]` 白名单删除,搭配 uninstall.ps1 提前把用户数据搬到 `%LOCALAPPDATA%\Insta360_HW\keep_data\` 临时区,Inno 删完再 `CurUninstallStepChanged=usPostUninstall` 时搬回。

改进的 InitializeUninstall + PreUninstall 逻辑:
```pascal
function InitializeUninstall(): Boolean;
var resultCode: Integer;
begin
  Result := True;
  UninstallKeepData := (MsgBox('保留用户数据?', mbConfirmation, MB_YESNO) = IDYES);
  if UninstallKeepData then begin
    // 提前搬用户数据到 %LOCALAPPDATA%\Insta360_HW\keep_data\
    Exec('powershell.exe',
         '-NoProfile -Command "& { $src = ''' + ExpandConstant('{app}') + '''; $dst = Join-Path $env:LOCALAPPDATA ''Insta360_HW\keep_data''; New-Item -ItemType Directory -Force -Path $dst | Out-Null; foreach ($p in @(''data'', ''config\local.json'', ''plugins\user'')) { $s = Join-Path $src $p; if (Test-Path $s) { $d = Join-Path $dst $p; New-Item -ItemType Directory -Force -Path (Split-Path -Parent $d) | Out-Null; Move-Item -Force -LiteralPath $s -Destination $d } } }"',
         '', SW_HIDE, ewWaitUntilTerminated, resultCode);
  end;
end;
```

## Task 5.4: pre-release checklist 脚本

**Files:**
- Create: `scripts/pre_release_check.ps1`

- [ ] **Step 5.4.1: 编写脚本**

Create `scripts/pre_release_check.ps1`:
```powershell
$errors = @()

# 1. git status clean
if ((git status --porcelain).Length -gt 0) { $errors += "uncommitted changes" }

# 2. VERSION 与 iss 一致
$version = (Get-Content VERSION -Raw).Trim()
$issContent = Get-Content HWAgent_Setup.iss -Raw
if ($issContent -notmatch [regex]::Escape("#define MyAppVersion `"$version`"")) { $errors += "iss version mismatch" }

# 3. REVISION == HEAD
$revision = (Get-Content REVISION -Raw).Trim()
$head = (git rev-parse HEAD).Trim()
if ($revision -ne $head) { $errors += "REVISION mismatch HEAD" }

# 4. UPDATE_NOTICE.assets 非空
. scripts/lib/ReleaseNotice.ps1
try { Assert-HwAgentNoticeHasAssets -Path UPDATE_NOTICE.json } catch { $errors += $_.Exception.Message }

# 5. HWAgent_release/ 存在且 exe mtime > VERSION mtime
if (-not (Test-Path HWAgent_release/Insta360_HW.exe)) { $errors += "release not built" }

# 6. pytest 快测试通过
pytest -m "not slow and not network" -q --tb=line
if ($LASTEXITCODE -ne 0) { $errors += "pytest fast failing" }

# 7. frontend build 通过
Push-Location frontend; npm run build 2>&1 | Out-Null; if ($LASTEXITCODE -ne 0) { $errors += "frontend build failing" }; Pop-Location

if ($errors.Count -gt 0) {
    Write-Host "PRE-RELEASE CHECK FAILED:" -ForegroundColor Red
    $errors | ForEach-Object { Write-Host "  - $_" -ForegroundColor Red }
    exit 1
}
Write-Host "ALL PRE-RELEASE CHECKS PASSED" -ForegroundColor Green
```

Run: `powershell -File scripts/pre_release_check.ps1`
Expected: `ALL PRE-RELEASE CHECKS PASSED`
