## 全局执行规则（每 task 均适用）

1. **基线记录**：task 开始跑 `pytest tests/ -q` 记通过数 N；结束后必须 = N + 该任务新增，**任何原有测试从绿变红都视为 task 失败必须回滚**。
2. **先红后绿**：每条新增测试必须先在未改实现下运行并**确认失败**（贴失败输出到 commit body），再写实现使其转绿。纯清理任务（明确标注）除外。
3. **改动范围硬边界**：只允许修改任务列出的文件。task 结束时 `git status --porcelain` 不得出现清单外文件（`__pycache__` / `.pytest_cache` 除外）。
4. **禁令**：禁改 `VERSION`/`REVISION`/`UPDATE_NOTICE.json`/`config/update_public_key.pem`；禁 `git push`（本仓库只允许 send-pack）；禁运行安装器/OTA/服务；禁触碰 `data/` 下任何文件；禁触碰未跟踪文件 `docs/fix_plan_bom_and_subprocess_2026-07-17.md`。
5. **单 task 单 commit**，消息格式 `fix|feat|refactor|test(<域>): <task 编号> <一句话>`。
6. **不允许打补丁**：禁止顺带重构、禁止换库、禁止"既然改到这里就……"、禁止"后续再优化"作为方案。任务书没写的一律不做。
7. **需人工/真机验证**的项目必须在 commit body 记录截图或 log 路径。

   ```python
   _PROCESS_MATERIAL_RE = re.compile(
       r"(?:^|[\s,;/()（）])"
       r"(测试点|跳线|安装孔|定位孔|TEST\s*POINT|MOUNTING\s*HOLE|MOUNTINGHOLE|FIDUCIAL|SCREW)"

   def _material_text(row):
       return " ".join(str(row.get(f) or "") for f in ("desc","name","model","pcb_package","pcb_footprint"))

   def _matches_process_material(row):
       m = _PROCESS_MATERIAL_RE.search(_material_text(row))
       return m.group(1) if m else None

   def _process_candidate_key(part_number: str, refs: list[str]) -> str:

   def _classify_no_partnumber(refs, row) -> str:
       upper = [r.upper() for r in refs]
       value = str(row.get("value") or "").strip()
       if NC_VALUE_RE.fullmatch(value):
           return "NC/未贴（无料号）"
       if any(r.startswith("SH") for r in upper): return "疑似屏蔽支架 SH*（无料号）"
   ```
