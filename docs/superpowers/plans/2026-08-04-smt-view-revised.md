## 0. 上一版错在哪

### 错误一：自绘方块，粗糙且没必要

上一版判断「PDF 文字层只覆盖 77%，所以放弃 PDF 底图、按 XY 自绘」。
**这个推理跳过了一种可能：PDF 只当底图，坐标仍用 XY，两者用共有位号自动配准。**

实测配准精度（443 / 355 个自动锚点，最小二乘仿射）：

| 页 | 锚点 | 该面 XY 位号 | 残差中位 | p90 | 最大 |
|---|---|---|---|---|---|
| 正面 | 443 | 450 | **0.104 mm** | 0.129 | 0.143 |
| 反面 | 355 | 587 | **0.104 mm** | 0.151 | 0.784 |

0201 器件长 0.6mm，0.1mm 中位误差是器件尺寸的 1/6，点必然落在器件上。

**结论：PDF 当底图 + XY 定位 + 共有位号自动配准。** 三者各司其职，同时拿到真实丝印底图和 100% 覆盖率。
与旧 `smt_layout` 的区别：那个要用户手拉 3 个锚点，这里有 443 个自动锚点，并且能算出残差自证精度。

### 错误二：NC 判定方式完全错

上一版假设需要「NC 汇总」作为输入。**成品 BOM 本来就不含 NC 料号**，所以：

```
NC 位号 = 坐标文件全部位号 − 成品 BOM 中出现的位号
```

只需要成品 BOM 一个输入，差集即 NC。上一版在缺 NC 汇总时把 1037 个位号全标成「贴装」
（截图实证：`1037 坐标位号 / 1037 贴装 / 0 NC`），并给出「将标记为仅坐标有」的错误兜底。

**用户已明确：直接采用差集，不再区分其中的非贴片件（测试点、屏蔽罩等一律计入差集结果）。**

## 3. 状态模型（差集口径）

设 `XY` = 坐标文件位号集合（1037），`BOM` = 成品 BOM 位号集合。

| 状态 | 判定 | 颜色 |
|---|---|---|
| `placed` 贴装 | `ref ∈ XY ∩ BOM` | 🟢 绿 |
| `nc` 未贴 | `ref ∈ XY − BOM` | 🔴 红 |
| `bom_only` BOM 有、坐标无 | `ref ∈ BOM − XY` | 画不出点 → **单独列清单** |

只有三类。**不再有 `non_smt` 与 `xy_only`**：
- 非贴片件（测试点/屏蔽罩）落在 `nc` 里 —— 用户确认直接用差集
- `xy_only` 与 `nc` 同义，合并

`bom_only` 必须给计数与清单，不得静默忽略。

## 4. 配准

**算法**：取本页 PDF 文字层位号 ∩ XY 位号作为锚点对（XY 的 mm 坐标 → PDF 页面 pt 坐标），
最小二乘拟合仿射变换（6 参数）。

**离群剔除必须做**：实测反面最大残差 0.784mm（有离群锚点，疑似标号被挪位标注）。
用一轮剔除：先全量拟合，去掉残差 > 3×中位数的锚点，再拟合一次。

**残差必须可见**：界面显示 `锚点数 / 残差中位 / p90 / 最大`（mm）。
若中位残差 > 0.5mm 或锚点 < 20，判定配准不可信 → **明确报错并拒绝打点**，
不得画出错位的点。

**面别配对**：PDF 页与 XY 面别按 `side` 匹配（XY 的 `mirror` 字段直接给面别，
实测正面 450 / 反面 587）。若某页匹配不上任何面别，该页不参与。

---

## 5. 裁剪

底图裁剪范围 = **配准后 XY 位号包络 + 边距**（建议 8% 或 3mm，取大者），
在 PDF 页面坐标系内计算后再栅格化。

不识别图框、不猜标题栏位置。这样能自动去掉图框与说明文字，让板面填满视口。

---

## 6. 视图（合并后）

同一份资料，同一次加载，切换只改配色，**不重新请求数据**：

1. **贴装状态**（默认）—— 🟢贴装 / 🔴NC
2. **NC 专项** —— 只亮红点，其余淡化到 15%（首件核对主场景）
3. **封装一致性**（提供了网表才出现）—— 🟠封装不符 / ⚪一致，点开显示「网表封装 vs BOM 封装/型号」
4. **备料风险** —— 等级非「优选/正常」标黄

视图 3 即合并进来的 `smt_package_check`。它现有输出已是按位号的
（列：`位号 / 网表封装 / BOM封装/型号 / 描述 / 名称 / 状态 / 说明`），直接 join 到图上，
同时**保留原有的可下载表格报告**（师傅要打印的场景仍需要表）。

## 7. 交互

- **正面 / 反面** 切换：按 `side` 过滤，切换对应 PDF 页；反面**不再额外镜像**
  （PDF 反面页本身已是从反面看的视角，再镜像会错）
- **左栏**：搜索（逗号分隔多位号）+ 状态分组计数 + 点击定位
- **点位号** → 平滑缩放居中 + 高亮 + 显示编码/描述/封装/坐标/判定理由
- **点图上标记** → 左栏同步选中并滚动可见
- 缩放到一定倍数显示位号文字，密集时自动隐藏
- 「打开原始位号图」按钮（新窗口，未裁剪的完整 PDF）

## 8. 流畅性（硬指标）

- 位号数据一次性加载，1037 条 **≤500KB JSON**
- 底图按裁剪区域栅格化并缓存；**PNG 用 `compress_level=3`，禁用 `optimize=True`**

- 缩放平移用 CSS transform，不触发重排
- 验收：1037 位号下缩放/平移**无可感卡顿**
